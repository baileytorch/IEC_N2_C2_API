# IEC_N2_C2_API
Proyecto con comunicación con API

Usaremos la API JsonPlaceholder

https://jsonplaceholder.typicode.com

Nos entrega 6 grupos de datos
- Publicaciones (posts): https://jsonplaceholder.typicode.com/posts
- Comentarios (comments): https://jsonplaceholder.typicode.com/comments
- Álbumes de fotos (albums): https://jsonplaceholder.typicode.com/albums
- Fotos que pertenecen a los álbumes (photos): https://jsonplaceholder.typicode.com/photos
- Lista de Tareas por hacer (todos): https://jsonplaceholder.typicode.com/todos
- Usuarios (users): https://jsonplaceholder.typicode.com/users
